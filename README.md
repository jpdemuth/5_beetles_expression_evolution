# 5_species_DC_evolution
## Analysis pipeline for inference of dosage compensation and balance in a phylogenetic context 
* Analysis_notebook.ipynb = Jupyter notebook with the analysis pipeline for the data contained in the combined_data_5_species.tar.gz archive
* r_analysis directory = contains scripts, inputs, and outputs for the ancestral state reconstructions and Pagel's lambda calculations
* Figure_5 directory = regressions of expression evolution versus sensitivity
* sc_og_list.txt is the list of 5-way single-copy orthologs necessary for ancestral state reconstruction
